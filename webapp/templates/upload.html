KP EPI Dashboard & Bulletin Generator

Upload your Excel file(s), get back the dashboard and weekly bulletin.

EPI Excel files

Drop in any combination -- a Coverage workbook, a VPD surveillance line list, or both. Each file is automatically identified from its actual content, so it doesn't matter which order you add them in, and you never need to upload every type just to see a dashboard:

  • Coverage only → get the Coverage dashboard
  • VPD surveillance only → get the Surveillance dashboard + bulletin
  • Both → get the full dashboard + bulletin

Monitoring/supervisory-visit uploads aren't supported yet -- no sample file has been received to build that pipeline against.

Bulletin key messages Optional

One message per line. These appear in the bulletin's footer (bulletin only builds if a VPD file is uploaded). Leave blank to use the default set.
